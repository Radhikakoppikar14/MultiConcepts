# MultiConcepts Website

A modern, responsive website built using React, TypeScript, and Vite.

## Run Locally

**Prerequisites:** Node.js and npm.

### 1. Clone the repository

```bash
git clone https://github.com/Radhikakoppikar14/MultiConcepts.git
cd MultiConcepts
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```

### 5. Preview production build

```bash
npm run preview
```
